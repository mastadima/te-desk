# TE Desk

Нативное macOS-приложение-компаньон для владельцев устройств Teenage Engineering.

## Скачать и установить

Скачайте [универсальный DMG](https://github.com/mastadima/te-desk/raw/refs/heads/main/dist/TE-Desk-0.1.0-macOS-universal.dmg), откройте его и перетащите `TE Desk.app` в `Applications`.

DMG содержит сборку для Apple Silicon (`arm64`) и Intel (`x86_64`). Требуется macOS 13 или новее.

Приложение ad-hoc подписано для проверки целостности, но не нотариализовано Apple. При первом запуске macOS может предупредить, что разработчик не проверен. Не отключайте Gatekeeper целиком. Если вы доверяете скачанной сборке, откройте приложение через Finder: нажмите на него правой кнопкой мыши, выберите «Открыть» и подтвердите запуск.

## Сборка из исходников

### Требования

- Mac с macOS 13 или новее.
- Xcode Command Line Tools с Swift 5.9 или новее.
- Для запуска универсального build-скрипта нужны стандартные инструменты macOS: `swift`, `lipo`, `codesign`, `iconutil`, `ditto` и `hdiutil`.

Если инструменты разработчика ещё не установлены, выполните:

```sh
xcode-select --install
```

### Получить исходники

Клонируйте репозиторий и перейдите в его папку:

```sh
git clone https://github.com/mastadima/te-desk.git
cd te-desk
```

### Собрать, запустить и проверить

Собрать и запустить приложение в режиме отладки:

```sh
swift run TEDesk
```

Запустить тесты:

```sh
swift test
```

Собрать релизную универсальную `.app` и установочный `.dmg`:

```sh
bash scripts/build-macos.sh
```

Скрипт собирает обе архитектуры отдельно, объединяет их в universal binary, создаёт иконку, подписывает приложение ad-hoc и проверяет подпись. Готовые файлы появятся в `dist/`:

- `TE Desk.app` — приложение.
- `TE-Desk-0.1.0-macOS-universal.dmg` — установочный образ с приложением и ярлыком `Applications`.

Временные файлы компиляции сохраняются в `.build/`; эта папка исключена из Git. Скрипт сборки нужно запускать на Mac — он использует инструменты macOS для упаковки и подписи.

### Выпустить новую версию

Перед публикацией проверьте изменения и тесты (`swift test`), затем соберите установщик. Для распространения через GitHub создайте Release и прикрепите к нему DMG из `dist/`. Публичный релиз без Developer ID-подписи и Apple notarization может показать пользователям предупреждение Gatekeeper; для бесшовной установки потребуется сертификат Apple Developer и нотариализация.

## Возможности

- Ищет подключённые USB-устройства через `system_profiler`; если USB-идентификатор недоступен, распознаёт поддерживаемые модели по точному имени внешнего тома, например `OP-XY`.
- Получает список физических внешних дисков через `diskutil`, затем показывает их смонтированные тома и фактическую ёмкость. Образы установщика и системные разделы в список не попадают.
- Проверяет страницы загрузок Teenage Engineering по запросу и показывает обнаруженные там версии ОС. Версию, прочитанную непосредственно с устройства, показывает только когда ОС её предоставляет; иначе её можно указать вручную.
- Ищет публичные проекты GitHub и обсуждения Reddit только после явного нажатия.
- Содержит каталог продуктов и приложений, сверенный с официальными страницами [products](https://teenage.engineering/products) и [downloads](https://teenage.engineering/downloads); ссылки ведут к первоисточникам.
- Не форматирует диски, не копирует и не записывает файлы, не скачивает и не устанавливает прошивки. Для обновления пользователь переходит на официальный сайт и самостоятельно подтверждает дальнейшие действия.
- Иконка приложения создаётся из векторного исходника `scripts/make-app-icon.swift` при сборке.

## Распознаваемые устройства и режим подключения

Этот список описывает распознавание в TE Desk, а не полную совместимость функций устройства. Приложение читает USB-описание macOS и сведения о смонтированном внешнем диске; оно не подключается напрямую к MIDI, USB-аудио или MTP, не читает содержимое устройства и не определяет установленную прошивку.

### Модели

| Модели | Как TE Desk распознаёт | Что нужно для обнаружения |
| --- | --- | --- |
| OP–XY | USB-описание macOS; либо внешний физический том с точным именем `OP-XY` | Для USB-поиска: включённое устройство и USB-кабель с передачей данных. Для MTP-переноса файлов нужен обычный режим устройства, `COM` → `M4` и приложение Field Kit. Для появления диска подключите OP–XY в режиме TE BOOT: выключите устройство, удерживайте `COM` при включении, подключите USB-C и нажмите `1`. TE BOOT предназначен для обновления; это не MTP-режим. |
| OP–1, OP–1 field, OP–Z | USB-описание macOS; либо внешний том с точным именем `OP-1`, `OP-1 field` или `OP-Z` | Сначала подключите включённое устройство кабелем USB с передачей данных и нажмите «Обновить». Если нужен специальный режим передачи или обновления, используйте официальную инструкцию именно для своей модели; TE Desk не управляет такими режимами. Имя тома `OP-1` само по себе не различает оригинальную и field-версию. |
| EP–133 K.O. II, EP–1320 medieval, EP–136 K.O.-sidekick, EP–40, EP–35 | USB-описание macOS; либо внешний том с точным именем `EP-133`, `EP-1320`, `EP-136`, `EP-40` или `EP-35` | Для USB-поиска оставьте устройство включённым и используйте кабель с передачей данных. Если требуется режим обновления или передачи, следуйте официальной инструкции для модели. |
| TP–7, TX–6, CM–15, OB–4 | USB-описание macOS; либо внешний том с точным именем `TP-7`, `TX-6`, `CM-15` или `OB-4` | Для USB-поиска используйте включённое устройство и кабель с передачей данных. TE Desk не переключает режимы и не обещает доступ к файлам или прошивке. |
| BC–1, PO–80 | Только USB-описание macOS, если система сообщает производителя Teenage Engineering или имя модели | Подключите устройство кабелем с передачей данных, если он предусмотрен устройством. Распознавание тома для этих моделей не настроено. |

Также USB-устройство будет отмечено как Teenage Engineering, если macOS явно укажет производителя `Teenage Engineering`, даже если его модель не входит в таблицу. Это не гарантирует, что macOS покажет серийный номер, память или версию ОС.

### Перед проверкой

1. Включите устройство и подключите его напрямую к Mac исправным USB-кабелем с передачей данных (кабель только для зарядки не подходит).
2. Если macOS показывает устройство в разделе USB, TE Desk сможет вывести доступное описание после автоматического сканирования или нажатия «Обновить». Для отображения объёма памяти внешний физический диск также должен быть смонтирован в macOS.
3. Не переводите устройство в загрузчик только ради обнаружения. Используйте загрузчик, режим Disk или MTP только если этого требует официальная инструкция нужной модели.
4. Для OP–XY смотрите [официальное описание MTP](https://teenage.engineering/guides/op-xy/com#mtp) и [шаги обновления через TE BOOT](https://teenage.engineering/downloads/op-xy): MTP для проектов и сэмплов — через Field Kit; диск TE BOOT относится к процедуре обновления.

## Ограничения

- macOS не сообщает универсальный номер прошивки через USB; у некоторых моделей его придётся сверить на самом устройстве. Страница загрузок производителя не доказывает, что найденная версия новее именно той, что установлена.
- Имя тома — только косвенный признак модели; при таком распознавании USB VID/PID не заявляются и не выдумываются. Если Reddit блокирует API, TE Desk предлагает открыть тот же запрос на сайте Reddit.
- OP–XY передаёт проекты и сэмплы по MTP: руководство TE указывает режим COM → M4 и приложение Field Kit для Mac. В TE BOOT устройство вместо этого появляется как диск для процедуры обновления; это не обычный MTP-доступ.
- Для этой логики сверены [руководство OP–XY от TE](https://teenage.engineering/guides/op-xy/com#mtp), [официальные шаги обновления OP–XY](https://teenage.engineering/downloads/op-xy) и [обсуждение MTP на OP Forums](https://op-forums.com/t/we-did-something-that-wasn-t-supposed-to-be-possible/31893).
- Каталог — локальный список, сверенный с сайтом при подготовке версии. Для актуального ассортимента в приложении есть прямая ссылка на сайт производителя.
- Установщик не подписан Developer ID и не прошёл notarization, так как для этого требуется сертификат владельца приложения. Он не должен распространяться как публичный релиз без подписи и нотариализации.

Поиск по USB выполняется локально. В сеть отправляются только названия устройств при ручном запросе к Teenage Engineering, GitHub или Reddit.
